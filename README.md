# Veloop Ad Reward Section

A modern React-based ad reward interface designed for Veloop Rewards. Users can watch ads, earn VEs, track their progress, and complete daily reward goals.

## Features

- Interactive ad reward cards
- Countdown timer for each ad
- Reward points (VEs) for completed ads
- Daily reward goal tracking
- Earnings and progress statistics
- Responsive UI
- Glassmorphism-based design
- Interactive hover effects
- Built with reusable React components

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React
